## 一、权限管理

| 方法签名 | Android | iOS | 返回值 | 说明 |
|---------|---------|-----|--------|------|
| `hasPermissions({bool withAndroidFineLocation = false})` | ✔️ | ✔️ | `Future<bool>` | 检查权限是否已授权 |
| `requestPermissions({bool withAndroidFineLocation = false})` | ✔️ | ✔️ | `Future<void>` | 请求权限 |

**参数说明**：
- `withAndroidFineLocation`: Android 12+ (API 31+) 时是否检查/请求精确定位权限

---

## 二、设备扫描

| 方法签名 | Android | iOS | 返回值 | 说明 |
|---------|---------|-----|--------|------|
| `startScan({ScanFilter? scanFilter, PlatformConfig? platformConfig, String? queueId})` | ✔️ | ✔️ | `Future<void>` | 开始扫描设备 |
| `stopScan({String? queueId})` | ✔️ | ✔️ | `Future<void>` | 停止扫描 |
| `isScanning({String? queueId})` | ✔️ | ✔️ | `Future<bool>` | 检查是否正在扫描 |
| `scanStream` | ✔️ | ✔️ | `Stream<BleDevice>` | 扫描结果流 |

**参数说明**：
- `ScanFilter`: 扫描过滤器，可包含 `withServices`、`withManufacturerData`、`withNamePrefix`、`exclusionFilters`
- `PlatformConfig`: 平台特定配置（如 AndroidScanMode）

## 三、设备连接

| 方法签名 | Android | iOS | 返回值 | 说明 |
|---------|---------|-----|--------|------|
| `connect(String deviceId, {Duration? timeout, bool autoConnect = false, ConnectionPlatformConfig? platformConfig})` | ✔️ | ✔️ | `Future<void>` | 连接设备 |

| `connectionStream(String deviceId)` | ✔️ | ✔️ | `Stream<bool>` | 连接状态流 |

**参数说明**：
- `autoConnect`: 是否启用自动重连（iOS/Android 支持，Windows/Linux/Web 忽略）

## 六、请求 MTU

| 方法签名 | Android | iOS | 返回值 | 说明 |
|---------|---------|-----|--------|------|
| `requestMtu(String deviceId, int expectedMtu, {Duration? timeout, String? queueId})` | ✔️ | ✔️ | `Future<int>` | 请求 MTU 值 |

**平台限制**：
- **iOS/macOS**: MTU 由系统管理，API 调用仅返回当前协商值（~185-517 字节）
- **Android ≤13**: 可请求一次（最大 517），默认 23
- **Android 14+**: 首个 GATT 客户端驱动 MTU 至 517，后续请求被忽略

|---------|---------|-----|--------|------|

## 八、配对管理

| 方法签名 | Android | iOS | 返回值 | 说明 |
|---------|---------|-----|--------|------|
| `pair(String deviceId, {BleCommand? pairingCommand, Duration? timeout, String? queueId})` | ✔️ | ✔️ | `Future<void>` | 配对设备 |
| `isPaired(String deviceId, {BleCommand? pairingCommand, Duration? timeout, String? queueId})` | ✔️ | ✔️ | `Future<bool?>` | 检查配对状态 |
| `unpair(String deviceId)` | ✔️ | ❌ | `Future<void>` | 取消配对 |
| `pairingStateStream(String deviceId)` | ✔️ | ⏺ | `Stream<bool>` | 配对状态变化流 |

**iOS 配对说明**：
- iOS 配对通过加密特征读写自动触发
- `pair()` 需要传入 `BleCommand` 指定加密特征
- `isPaired()` 若不传 `pairingCommand` 返回 `null`

## 九、蓝牙状态

| 方法签名 | Android | iOS | 返回值 | 说明 |
|---------|---------|-----|--------|------|
| `getBluetoothAvailabilityState({String? queueId})` | ✔️ | ✔️ | `Future<AvailabilityState>` | 获取蓝牙可用性状态 |
| `availabilityStream` | ✔️ | ✔️ | `Stream<AvailabilityState>` | 蓝牙可用性状态流 |
| `enableBluetooth()` | ✔️ | ❌ | `Future<void>` | 启用蓝牙 |
| `disableBluetooth()` | ✔️ | ❌ | `Future<void>` | 禁用蓝牙 |

**AvailabilityState 枚举值**：
- `unknown`: 未知状态
- `unavailable`: 蓝牙不可用（设备不支持）
- `poweredOff`: 蓝牙已关闭
- `poweredOn`: 蓝牙已开启

| 功能 | Android | iOS |
|------|---------|-----|
| 程序化开关蓝牙 | ✔️ | ❌（需系统设置） |

## 使用示例

```dart
import 'dart:typed_data';
import 'package:universal_ble/universal_ble.dart';

// 检查权限
bool hasPerm = await UniversalBle.hasPermissions();
if (!hasPerm) {
  await UniversalBle.requestPermissions();
}

// 扫描设备
UniversalBle.scanStream.listen((BleDevice device) {
  print('发现设备: ${device.name} - ${device.id}');
});
await UniversalBle.startScan(scanFilter: ScanFilter(withServices: ['180a']));

// 连接设备
await UniversalBle.connect(deviceId);

// 发现服务
List<BleService> services = await UniversalBle.discoverServices(deviceId);

// 读写数据
Uint8List value = await UniversalBle.read(deviceId, serviceUuid, characteristicUuid);
await UniversalBle.write(deviceId, serviceUuid, characteristicUuid, Uint8List.fromList([0x01]));

// 订阅通知
UniversalBle.characteristicValueStream(deviceId, characteristicId).listen((data) {
  print('收到数据: $data');
});
await UniversalBle.subscribeNotifications(deviceId, serviceUuid, characteristicUuid);

// 断开连接
await UniversalBle.disconnect(deviceId);
```
